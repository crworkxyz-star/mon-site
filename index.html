Résolution d'équations trigonométriques

1. Les équations fondamentales (dans ℝ)

Pour tout réel k ∈ ℤ :

Cosinus

cos(x) = cos(a)  ⟺  x = a + 2kπ  ou  x = -a + 2kπ

Sinus

sin(x) = sin(a)  ⟺  x = a + 2kπ  ou  x = π - a + 2kπ

Tangente

tan(x) = tan(a)  ⟺  x = a + kπ  (avec x, a ≠ π/2 + kπ)

2. Valeurs remarquables

x (rad) 0 π/6 (30°) π/4 (45°) π/3 (60°) π/2 (90°) π (180°)
cos(x) 1 √3 / 2 √2 / 2 1/2 0 -1
sin(x) 0 1/2 √2 / 2 √3 / 2 1 0
tan(x) 0 √3 / 3 1 √3 Indéfini 0

3. Méthode pas à pas

  1. Isoler le terme trigonométrique pour obtenir la forme cos(X) = c ou sin(X) = c.
  2. Vérifier que la valeur c est bien dans [-1 ; 1] (sinon, aucune solution réelle).
  3. Identifier l'angle de référence a tel que cos(a) = c ou sin(a) = c.
  4. Appliquer la formule générale avec + 2kπ (k ∈ ℤ).
  5. Restreindre aux solutions de l'intervalle demandé (ex: [0 ; 2π[ ou ]-π ; π]) en testant des valeurs de k.
